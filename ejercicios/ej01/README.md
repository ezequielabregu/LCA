## **Pauta:**
Busquen una obra de arte (sonora, visual, audiovisual, etc.) en la que aparezca alguna operación vinculada a estructuras o pensamiento algorítmico. Puede ser una obra que sea un algoritmo en sí, una obra creada gracias al output de un algoritmo, o una obra que no podría existir sin un algoritmo creado por terceros (externo al propio artista).
Para compartirla, incluyan: nombre de la obra, fecha de creación, autoría y un comentario personal explicando por qué la consideran valiosa para traer a este grupo de estudio. Sumen también un link de referencia para poder ver alguna documentación.<br>
<br>
Ejemplo: <br>
Les comparto una pieza hecha con Pure Data: "AHORA. Una canción en la Superficie Hipertemporal" (2013), de Mene Savasta Alsina y Hernán Kerlleñevich. Es una instalación sonora interactiva en la que los sonidos se controlan según la presencia y el movimiento del público. Los artistas desarrollaron un algoritmo para una serie de obras, entre las que además de Ahora, se encuentran Mientras, Aquí, Piotr, etc. Lo interesante es cómo el algoritmo, oculto al espectador, funciona como estructura central: analiza los sensores de presencia y determina qué sonidos se reproducen.<br>
